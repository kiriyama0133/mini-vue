# MiniVue

一个基于 TypeScript 从零实现的 Vue3 核心原理学习项目。

## 项目作用

MiniVue 旨在通过手写 Vue3 核心模块，加深对现代前端框架底层原理的理解。

主要学习内容：

- Virtual DOM 与 VNode 设计
- Renderer 渲染流程
- Patch 更新机制
- Diff 算法
- 响应式系统原理
- Vue3 Runtime Core 架构设计

通过实现一个简化版 Vue Runtime，理解 Vue3 从状态变化到 DOM 更新的完整流程。

---

## 技术栈

- TypeScript
- Vite
- pnpm
- Prettier
- Husky

## 常用指令

```bash
pnpm install #安装依赖
pnpm release #分发，版本升级
pnpm build #构建
```
